# cryptographie-et-sécurité
Cryptanalyse des chiffrements de César et Vigenère, analyse fréquentielle, indice de coïncidence, attaque par dictionnaire, brute force et authentification par socket

# Exercice 1 - Cryptanalyse
-Chiffrement et déchiffrement de César et Vigenère
-Analyse fréquentielle
-Calcul de l'indice de coïncidence 
-Cryptanalyse automatique et test de Kasiski

# Exercice 2 - Mot de passe faible
- Recherche d'un mot de passe à partir de son empreinte MD5
- Utilisation d'une attaque par dictionnaire

# Exercice 3 - Archive ZIP protégée
- Génération de mots de passe possibles
- Recherche par force brute

# Exercice 4 - Authentification
- Communication avec un serveur à l'aide de sockets
- Recherche d'un code PIN par force brute

# Technologies utilisés
- Python
- Socket
- Hashlib
